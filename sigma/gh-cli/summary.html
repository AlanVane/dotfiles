本课立住的模型

PR 是服务器上的记录，不是补丁包。记录里只有 head/base 两个端点（ref + SHA）； 页面 diff 是 GitHub 拿两个 SHA 现算的。改 base、往 head 再 push，diff 自动变。
git 主动执行 credential helper。gh auth setup-git 把 !/usr/bin/gh auth git-credential 写进 git 配置；git 要密码时调用它， 它把 gh 存的 token 当密码交出去。
私有仓库的 404 是在掩盖 403。没权限时 GitHub 不暴露仓库是否存在， 防止无权限者枚举私有仓库。
跨 fork 的 PR head 要写 owner:branch。只写分支名， 服务器认不出是一百个同名分支里的哪一个。
各自绿 ≠ 合起来绿。A 改名、B 新增旧名调用，两边单独跑都过，合并才炸（语义冲突）。 「Require branches to be up to date」就是逼你先 main → feature 再重跑 checks。
squash vs rebase。都要线性历史：功能只留一笔用 --squash， 每笔 commit 都有意义（利于 bisect）用 --rebase。
