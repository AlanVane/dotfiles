你自己推出来的规则

两态规则：版本相同 → 修改随行；版本不同且冲突 → git 拒绝切换。git 永不静默丢修改。
桌子模型：分支 = 贴在 commit 上的便利贴；工作目录 = 所有分支共用的桌子。换便利贴不动桌子。
tnr 自动存的两个作用：防止切换被卡住 + 给新分支一个干净的起点。
小抄模型：stash 存的是改动本身（小抄），不绑分支；pop 往当前桌面誊——成功扔小抄、失败保留。冲突时能誊的先誊，誊不动的标记出来。
盲区规则：git s 和 stash 默认都只管已追踪文件，新文件要 -u 才带上。
地址标签：push -u = 这次指定完整地址 + 存进配置；以后 ps/pl 自动查表。裸 push 没地址会报错。
删除的两道安全网：td 删前先同步（push = 给内容做远程备份，丢的只是标签）；branch -d 拒绝删未合并分支。后悔了用 reflog + 新分支找回。
tmg vs td 的删除：tmg 合并已把成果存进 base 分支所以不怕丢；td 的成果可能没保存，所以先同步再删。
