| 3   | helper 探测命令         | 「behind-count 输出数字所以 `-n` 测不了」——结论对、机制错 | shell 万物皆字符串：`0` 也是非空字符串，`-n` 测的是「空白与否」          | resolved | 用户复述：「"0" 语义=没有 behind，但 -n 测试为真=有 behind，两个意思不匹配」                      |

| 5   | td（删除 topic 分支）   | 「远程无分支时 td 直接删本地，成果会丢」                  | 未实测猜测 git 的破坏性行为，忽略 branch -d 安全网（未合并分支拒绝删除） | resolved | scratch repo 实测报错「没有完全合并」→ 成果不丢；追问 commit 位置 + 强制删除命令全对              |
