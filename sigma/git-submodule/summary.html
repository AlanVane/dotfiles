本次亮点

  • 三态前缀全部落地：- 未初始化 / 空格 已对齐 / + 已偏离，每一态都配了一个亲手实测的场景
  • 自己推出「pull 只取对象、不动签出」：从 origin/main 已指向新提交、而 HEAD 仍停在旧 SHA 的矛盾里读出这一层机制
  • 误解 #3 反证链销账：子仓库内部「无文件要提交，工作区干净」却仍被 add 改写便签——一击拆除「add = 记录本地修改」模型
  • 自相矛盾自查：两格填空互相打架（一边说钦定是 d26c1e2、一边说 update 后停在 ae030b6），点名后一秒自纠
  • 自评首次偏低：自评「基本会」，rubric 85% 过关且换形一次命中——校准后可直接采信

误解记档

  • 「子模块登记 = 一包文件」active · 换形两连不过，需第三次
  • 「status 没显示 SHA → 账变了」（摘要当账本读）10-23 换形通过 · 关口关闭
  • 「M awesome-ui 一律 add+commit 修」（gitlink 当普通文件）10-23 反证链 + 换形销账

遗留尾巴

  • 方向判断：见到 gitlink 先比对两个 SHA（index 钦定 vs 工作区实际）再动手，别让普通文件反射先跑
  • 160000「钦定便签」独立复述忘：讲解后现学现测过，10-25 复述把关
  • 命令标签召回弱：双 config 文件名、update 方向——靠拆字 + 读提示原文纠
