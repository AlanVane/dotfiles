01目的与分诊（急救的三条路）

✓ 85%

误操作发生时先问「哪条路」：reset 挪指针、stash 藏 WIP、revert 造反向——急救前先分诊，避免用错刀。

02reset 三态（指针 + 暂存区 + 工作目录）

✓ 85%

--soft / --mixed / --hard：三态 = 动几层现场。「没」= 没名字指着，不是没对象。

03reflog（操作日志 = 安全网）

✓ 85%

HEAD 的移动流水账：左边 SHA = 落点，动词 = 凶手，@{n} = 行号。本地私有，clone 不抄。

10-14

04reflog 急救实操（找回丢失 commit）

✓ 90%

事故条的上一条 = 事故前最后位置。reflog 找 SHA → reset / branch 接回三层现场。

10-14

05stash 解剖（WIP 的真实形态）

✓ 90%

stash = 双父 commit（基线 + 暂存区快照 + 工作目录 tree）挂 refs/stash；apply 留账、pop 删账、掉落靠 fsck 翻尸。

10-14

06stash 的坑（pop 冲突 / 未跟踪 / 栈序）

✓ 90%
