📋 概念清单

# 概念 得分 一句话收获
01 目的与分诊 ✓ 85% reset 挪指针 / stash 藏 WIP / revert 造反向——急救前先分诊
02 reset 三态 ✓ 85% soft/mixed/hard = 动 1/2/3 层现场；「没」= 没名字，不是没对象
03 reflog 安全网 ✓ 85% HEAD 流水账：SHA=落点，动词=凶手，@{n}=行号；本地私有不随 clone
04 reflog 急救实操 ✓ 90% 事故条的上一条 = 事故前最后位置；reflog 找 SHA → 接回三层
05 stash 解剖 ✓ 90% stash = 双父 commit（基线 + 暂存区快照 + 工作目录 tree）挂 refs/stash
06 stash 的坑 ✓ 90% pop 先施用成功才删账；-u 一锅端，精确制导靠先 add；push 不带 stash
07 综合分诊演练 ✓ 90% 已推用 revert / WIP 用 stash / 丢 commit 用 reflog+reset / 漏 add 用 amend

🏆 高光时刻

自推导链：拆词面推 --no-ff（禁快进 = 必造新 commit）→ 三态命名自悟「动几层」→ stash 双父结构自主填格 → amend 课外工具自判「没 push 所以能用」的边界
抓错能力：老师手写账本两行同 SHA 矛盾被当场抓出——急救医生不轻信任何输出，包括老师的
三次翻案全部由押注驱动：「彻底消失」×2、「先删账」×1——每次都是先亮直觉、再被实测打脸、然后自己讲出正确机制。直觉并不可耻，不验证才可耻

🔍 误解战报（3 战 3 胜）

误解 翻案实验 状态
hard reset 后内容「彻底消失」 cat-file -t → commit ✓ 销账
reflog 随 clone 共享 clone → 只有 1 条 ✓ 销账
pop 先删账再施用（冲突 = WIP 危险） 制造冲突 →「储藏条目被保留」 ✓ 销账
