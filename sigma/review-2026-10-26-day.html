🔍 关键证据

① gitlink 的 SHA：账上有号码，货在别家 
$ git -C dev-site ls-files -s | grep 160000
160000 0a6ed07c… 0	ui          ← 账上白纸黑字

$ git -C dev-site cat-file -t 0a6ed07c
致命错误：could not get object info   ← 主仓库查无此物

$ git -C dev-site cat-file -t HEAD
commit                                 ← 对照：命令与对象库都正常

$ git -C dev-site/ui cat-file -t 0a6ed07c
commit                                 ← 同一串号码，子仓库认得
② lock 挡住了 prune 
$ git worktree list
.../wt-lock/hotfix 03aaf62 [hotfix] locked

$ rm -rf ../hotfix && git worktree prune -v
（无输出，退出码 0）                    ← 登记原样留着

$ git worktree unlock ../hotfix && git worktree prune -v
删除 worktrees/hotfix：gitdir 文件指向一个不存在的位置
