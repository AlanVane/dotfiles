# Learner Profile

Updated: 2026-10-14

## Learning Style

- Preferred explanation mode: concrete examples（scratch repo 实测最能落地；抽象机制问题常答「不知道」，需梯子降阶到具体场景）
- Pace: moderate — 识别类问题快，机制复述类问题需要时间，多次「不知道」后经降阶梯子可完成推理
- Responds best to: 反例实验 + 预测问题（先预测再实测，矛盾驱动模型更新）；梯子末格填空（worked example 留最后一步）——填空梯子在 git-rebase 再次验证有效
- Struggles with: 无提示地复述机制；新场景预测（模型未内化时会退回旧误解）
- 优点：细节复述准确（SHA、命令全名、行号都能精确引用）；**抓错能力**（10-14 抓到老师手写账本两行同 SHA 的矛盾——不轻信输出，值得保持）

## Misconception Patterns

- 未验证时倾向凭直觉猜 git 的结果，且偏向「危险/否定」方向（「会覆盖」「会丢失」「看不到」「会提示输入」）（seen in: git-aliases 误解 #4/#5，git-rebase 概念 6/7，10-10 复习 tn/tnr 误记实测，**10-14 再证：hard reset 后「内容彻底消失」选 A**——与自己讲过的「git 从不删对象」矛盾仍不自察，cat-file 实测才翻案）
- shell 符号/术语易混：`\|` vs `\|\|`（seen in: git-aliases）
- 把工具输出当有类型的值而非字符串：`0` 是数字不是字符串（seen in: git-aliases）
- 模型复述正确 ≠ 已内化：正确复述后新场景仍会触发旧误解，需实验 + 应用双重确认才算解决（seen in: git-aliases 误解 #4，git-rebase 误解 #4；10-10 复习再证「3 个 commit 都在」混淆「内容在 vs 原件在」；**10-13 再证：rebase 误解 #1 复制重放复习复发**——初答「原样搬运」+ 两轮追问仍坚持，tag 旧线实测后才自纠；**10-14 三连证：误解 #1 第二次复发**——押注题（看图前）又押「原照片挂 E 后面」，实测翻案后自称「看错图」被反驳（是模型不是眼力）→ 追问机制自纠；对策升级：**押注题连续两次押对才销账**，且必须是实测前的预测而非看图判读）
- 表述混淆：机制说对但措辞/归因错位，或把另一命令的习惯混入（「push 之后才有历史」；merge 的 git commit 混入 rebase 收尾——**10-14 初答再次混入**；cherry-pick 的 `A..B` 范围语法误搬给 rebase，参数角色不同：名单 vs 基线）——反问澄清/实测即可纠，但**收尾命令类的混入已两次复发**，复习要专门出（seen in: git-aliases 概念 6，git-rebase 概念 6/4/4，cherry-pick 概念 4→rebase）
- 「想不出来」后由讲解填入的机制，若未复述会停在听懂层（seen in: cherry-pick 概念 7 的 SHA 哈希、空提交网两个洞；10-11 复习再证「想不出来」×2）——对策：讲完必须留一格让他填，或交回他写命令（本轮 Q2 命令自写即通过）
- 答题时倾向跳过「为什么/半问」直接给操作方案（10-14 密集出现：merge 被拒只给 stash 方案不答原因、考核 Q1 跳 status 半问、reflog 翻译追加问跳过、「不知道」时默认请讲解）——对策：点名追问被跳的那半问，屡试不爽（每次追问后都能补对）
- 课堂结论若以「必/绝不」表述，他会长期当硬规则记——**教法侧风险**（10-11「必出新编号」被实测推翻，他原直觉反而是对的）——讲机制时默认留例外

## Metacognition

- Self-assessment accuracy: well-calibrated 为主（git-aliases + git-rebase 多次一致）；occasional 偏高（cherry-pick 概念 6/7 自评「扎实」均高于 rubric 半档——应用对、机制需推导）；**10-15 出现首次偏低**（急救箱综合分诊四题全对自评「基本掌握」——欠分点只是注脚级细节，选路本身扎实）
- Fluency illusion frequency: occasional — 复述正确后新场景仍触发旧误解；解决靠双实验 + 应用检验
- 间隔复习健康：10-10 清 12 项复习债全过，仅 3 处轻度 decay（均经追问/实测校准），无误解复发
