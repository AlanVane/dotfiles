关键领悟

  • 一个 .git：对象库和分支账全仓库共用，HEAD / 暂存区各目录专属
  • 同一分支不可两处签出——分支锁防「同行改动被静默盖掉」的哑事故
  • 手动 rm 留下尸登记，需 prune 清；登记被删后 checkout / 重建都会被拦
  • 按任务寿命分派：分钟级活用 stash（欠一笔 apply 的债），天级并行开 worktree（切换需求消失，不切、并行）
