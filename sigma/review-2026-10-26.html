主仓库 status               →  M ui

③ detached 提交后：无人认领 
detached 里 commit          → 35cd076 提交成功
git branch --contains 35cd076 → 无分支
再 git submodule update     → HEAD 回 0a6ed07
git reflog                  → moving from 35cd076… to 0a6ed07…

🩺 三条翻车的共同病根

押注前把 git 想成门卫（会拦：detached 提交被拒）或保姆（会自愈：便签自动跟随、对象随目录消失），而它其实只是一本只记账的账本——对象活不活看可达性，便签改不改看你有没有 add。
