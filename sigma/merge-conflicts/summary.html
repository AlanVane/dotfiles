🏆 本课最大亮点

档案挂账当场清偿：git-rebase 课留下的「merge 三方对比机制为讲解所得」——诊断第一题就自愈了。三方 = 共同祖先 + ours + theirs，由重放模型的「基线」概念直接推导而出。**补课变成了查账**。
押注 9 连中：FF 直线 / 分叉双父 / 冲突停车 / diff3 三段 / 最终三合一 3/3——本课你的直觉和 git 的行为零冲突（对比急救课 3 次翻案）。基线模型在 merge 领域的迁移是完整的。
工具自写率：git diff --diff-filter=U（找冲突名单）、merge --continue / --abort（构词法推导）——未教先会或一点通。

⚠️ 唯一记档弱点

裁决手误：编辑冲突文件时顺手删掉了无争议行（v1）——「裁决只动打架段」已入教训。真实场景里这类手误无人复核，比冲突本身危险。

📖 带走的口诀

快进 = 目标是源的祖先，只挪指针
冲突三段：ours / base / theirs
裁决只动打架段 → add → merge --continue
独占未推 → rebase 整理；共享已推 → merge（只加不改）
